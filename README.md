# UNP-REGRESSION-INSURANCE-DATA
# Medical Insurance Cost Prediction Using Regression

## Project Overview

This project focuses on predicting medical insurance charges using regression machine learning techniques.

The objective is to analyze the factors that influence medical insurance costs, build regression models, and compare their performance using different evaluation metrics.

## Dataset

The dataset contains information about individuals and their medical insurance charges.

The main variables include:

- Age
- Sex
- BMI
- Number of Children
- Smoking Status
- Region
- Medical Insurance Charges

The target variable for prediction is **Medical Insurance Charges**.

## Data Preprocessing

The following preprocessing techniques were performed:

- Checked for missing values
- Converted categorical variables into numerical form
- Performed exploratory data analysis
- Selected relevant independent variables
- Divided the dataset into training and testing sets

## Regression Models

The following regression models were implemented and compared:

- Linear Regression
- Decision Tree Regression
- Random Forest Regression

## Model Evaluation

The models were evaluated using the following performance metrics:

- R-squared (R²)
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)

## Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Results

The regression models were compared based on their R², MAE, MSE, and RMSE values.

The model with the best overall performance was selected based on its predictive accuracy and error metrics.
